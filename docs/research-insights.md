# 研究心得

这份笔记积累具体研究中的观察、解释和可检验建议，供研究者与 agent 在遇到相似问题时按需阅读。比较条件难以对齐、首稿与修订的评价混在一起，或修订后又出现新证据时，可从相关小节读起。后续经验继续追加在这里；跨案例的支持与反例积累到足以说明适用条件后，再考虑提炼为通用指南。

## 从条件关系中获得可靠价值

一次围绕单细胞扰动预测争议的 GPT 案例，经实际修订和独立复核后，完成了所约定的文献解释与公开结果表核查。它的可靠价值集中在恢复“任务—可用信息—预测输出—评价事件”的关系，并在可比交集上做原表级核算。例如，预测未测单基因、预测两个已测单体的未测组合，以及辨认非加性事件，各自需要不同的信息与读出。[GEARS 原始工作](https://www.nature.com/articles/s41587-023-01905-6)、[线性基线评测](https://www.nature.com/articles/s41592-025-02772-6)及[共同信号与任务特异能力工作例](../core/docs/methods/worked-examples/common-and-task-specific.md)提供了可继续检查的公开材料。

回看这类结果时，分开四个层次更容易判断它能支持什么：

| 判断层次 | 这次经验提示怎样核对 |
| --- | --- |
| 研究方向是否命中 | 议题确实接近领域中的比较与评价问题；种子论文已指定，发现新主题的能力还需要另设检验 |
| 来源是否读准 | 回到具体段落、公式、图与实现，检查输入角色、数据对象、划分和评价含义；方向相关之后，读源仍需逐项核实 |
| 实际做了哪些工作 | 公开表的核算与独立复算提供了执行证据；完整模型训练与原始加载过程各自需要相应运行材料 |
| 能用于什么决定 | 条件解释可帮助选择基线与设计评价；新背景预测、实验排序与前瞻用途继续接到相应数据和实测终点 |

有界专题的完成，按该专题承诺的对象、问题和交付判断。若目标扩大为一份当前的全领域综述，来源覆盖、候选方法与反例搜索也随之扩大。交付时同时说明已完成的范围、仍开放的研究目标与下一步责任，读者便能据此接手。

## 保留首稿—复核—修订—最终接受的路径

这个案例中，复核实质补上了输入、评价、数据对象和划分之间的关系。首稿、复核意见、实际修订和具名最终接受应当各自保留：首稿按原文评价；复核说明缺了什么及其影响；修订落实到具体文字或分析；最终接受指向所评版本与范围。

对流程的改进，可以先关注复核怎样补实关系、修订是否准确落地，以及接受前是否重核关键原文。首稿继续承担清楚表达问题、证据和初步结论的责任，后续复核负责发现与修复遗漏。评价这条路径时，同时观察首稿质量和经复核后的成果，分别记录各阶段的贡献。具体操作可按[回应路线与修订验收](../core/docs/methods/guides/revision-responses-and-acceptance.md)选择。

## 修订后综合整理，再判断下一轮

在没有资源截止、且本轮修订已经落实后，先做一次综合整理，再决定是否开启新轮次，是一条可用的推进路线。整理的重点是把新证据接回当前承诺与主张：

| 新证据带来的影响 | 当前可采取的动作 |
| --- | --- |
| 发现原承诺仍有缺项，或足以推翻、明显削弱当前主张 | 留在本轮，补解释、补分析、收窄或撤回相关主张，再复核受影响部分 |
| 对研究有价值，主要回答超出本轮范围的新问题 | 写清新问题、来源与可能改变的决定，作为下一轮入口 |
| 需要新数据或实验才能区分解释 | 接到明确的后续验证，说明所需材料、比较对象、预期读出与负责接手者 |

在修订过程中读到足以改变当前结论的反证时，就及时接回修订。修订后的综合整理再统一回收这些变化，检查遗漏，并形成下一步选择。

本次后续领域对照列入了 [Systema](https://www.nature.com/articles/s41587-025-02777-8)、[Miller 等的正式发表版](https://www.nature.com/articles/s41587-026-03307-w)和 [Science Advances 的任务比较](https://www.science.org/doi/10.1126/sciadv.aed3414)。这三项来源未纳入原 GPT 案例；若继续写当前领域综述，应把它们纳入新一轮的范围与论证检查。旧案例的实际阅读和接受范围按当时记录保留。

## 没有时限时，怎样停止本轮阅读

停止点可以来自研究义务、证据影响和行动价值。综合整理时问三个问题：本轮承诺是否已经交付并得到相应复核；新证据是否会改变当前主张或下一步选择；继续查找能区分哪一种解释、改变哪一项行动。

当本轮义务已履行，重要反证已处理，剩余阅读主要扩展用途时，可以结束这一轮，并把扩展问题交给下一轮。方向明确且调研充分的工程问题，可以进入有界试用并保留未决问题；理论问题、前期探索和下游影响大的长流程决定，则给反例、竞争解释和可重复性检查更多份额。

## 怎样继续积累

追加心得时，保留产生它的背景、所用依据、当前解释、适用条件和可改变建议的观察。后续案例若支持、修正或推翻某条心得，接着补记原因与关系。已有课题笔记足以承载的材料可以沿用原位置；这里保留值得回看的综合认识，按问题触发阅读。通用指南的提炼留待跨案例证据与适用条件清楚之后。

## 复核意见也回到图与公式

后续同题案例给出了另一条具体经验：一次复核将图的纵轴归一化参照误读成图中百分比的比较对象，作者据此修订。重新查看 [GEARS 图 2f](https://www.nature.com/articles/s41587-023-01905-6/figures/2)后，可以分别恢复两种关系：纵轴以 no-perturbation 归一化，黑色括号则连接 CPA 与 GEARS。相对改善对应 `1 − NMSE_GEARS / NMSE_CPA`；共同归一化的分母在这个比值中约去。

这提示我们把“复核确实发生”“作者已按意见修订”和“新增解释得到原始证据支持”分别检查。评阅者身份提供责任关系，图、公式、代码和实际结果承接具体判断。遇到跨图或跨段落的解释时，可以先写清正在核对的参照、比较对与目标量，再检查它们怎样连接；对修订中新加入的解释继续做同样的核对。原始错误和后续纠正随版本保留，为下一次相似问题提供可定位的经验。

## 先确定输出，再判断它支持什么

SAVER 与 COMMOT 的小规模接续研究提示，同一个方法名称可以包含用途不同的输出。SAVER 的后验均值、抽样与修正相关分别进入点值、分布和关联评价；COMMOT 的默认混合评分与纯全局分配也有不同的资源含义。方法选择可以先问：当前程序实际返回什么，它怎样进入下一判断，哪种参照能够检验这次用途。对象、配置和评价量对齐之后，再解释方法之间的差异。

两案还提醒我们把总体摘要接回具体对象。SAVER 的点误差改善与 Gini、方差和关联的表现需要分别观察；COMMOT 的总量和发送者排名稳定时，局部受体的配体份额仍可能改变。若下一步动作针对特定基因、细胞或通讯边，评价也应保留那个层次的结果。冻结后的负对照和敏感性比较帮助辨认变化来自哪里。[案例、观察与适用条件](research/saver-commot-continuity-2026-11-04.zh.md)保留两案的实际范围。

这轮支持继续使用现有首稿、独立评阅、修订与接续路线。初稿的小错误通过实际修订处理，后续结果又经过复核；新增知识先留在带条件的工作例中。经验条目与调整的对应已经可见，逐次执行前重读的完整可观测性仍可在后续使用中检查。
