# 研究路径视图（原型）

本原型回应 [issue #6](https://github.com/vvcchh0/BioInformaticsHarness/issues/6)：把一个课题目录里的研究记录整理成一页给人读的视图，让读者看到研究现在在哪一步、为什么走到这里、接下来做什么，并能从任何结果或判断反查它的来路。

## 运行

在 core 目录运行，只需要 Python 标准库：

```text
python -B -m scripts.research_support.study_view --root examples/research-support/study-view/demo-study --out .scratch/study-view/demo.html
```

用浏览器打开生成的 HTML。页面是单个离线文件，记录内容嵌在其中，也可以跳回原始文件。`--model-out` 另存一份 JSON 视图模型，供工具或 agent 读取。输出文件已存在时命令拒绝覆盖。

## 页面内容

- **阶段主线**：按[研究推进主线](../../../docs/methods/guides/research-guidance-cycle.md)的六个阶段排列，标出已经过、当前和未到达的阶段，以及每个阶段已记录或尚未记录的引用。
- **总览**：当前阶段与结构检查状态、方向决定及其理由、下一动作和本阶段可能的出口；版本经过一栏列出各周期版本，以及每一版相对上一版改变了什么。
- **分支与选择**：已选定、待讨论和未选定的方向，各自的理由、成本、替代和改判条件。暂缓与停止的方向保留在页面上。
- **证据链**：来源 → 发现 → 方法候选与研究问题 → 候选方向。点击任一项会高亮它的来路与去向。
- **修订链**：评阅意见 → 修订请求 → 处理路线 → 任务 → 产物 → 主张与复核，包括未选路线和尚未完成的任务。
- **缺口与检查**：研究周期检查器的全部检查项，以及目录中无法解析的引用。
- **详情面板**：所选记录的摘要、字段、来路、去向和原件。

## 关系从哪里来

视图只画记录中明确写出的关系：根目录相对的 `*_ref` 路径，以及证据图、讨论和修订记录中声明的 ID。不从正文推断关系，也不生成摘要；卡片上的文字取自记录本身的字段。

- 值为 `null` 的引用显示为“未记录”，表示这一步尚未发生，不算缺口。
- 写了但找不到的路径或 ID 列为缺口，不画出关系。
- 阶段状态和下一动作来自现有的 `research_cycle` 检查器；检查只说明结构是否齐备，科学充分性仍由研究评价流程判断。
- 不读取点开头的目录，不跟随符号链接。

识别的记录类型：研究周期、方向讨论、来源账本、证据图、周期修订决定和 `research-revision-v1`。其他 JSON 与文本文件列在“原始文件”中，可以查看内容。字段与关系的完整对应见[机器记录](../../../machine/tools/study-view.json)。

## 演示课题

[demo-study](demo-study/README.md) 的全部内容都是虚构的，只演示结构：`cycle-v1` 停在向人说明并讨论，`cycle-v2` 记录了人的方向选择；三个候选方向分别被选定、暂缓和不选；`revision/` 演示一条完整的评阅修订链。两个周期版本都通过研究周期检查器。修订记录中的人工复核尚无评阅回执，修订检查器如实报告为未确认。

## 梳理时发现的结构问题

以下是对照文件结构时看到的关系缺口和重复表达，供讨论：

1. **修订记录不知道自己属于哪一轮。** `research-revision-v1` 没有 `cycle_id`、`study_id` 或版本字段，视图只能按它所在的目录展示，无法挂到某个周期版本下。
2. **证据图不指明自己的来源账本。** 证据图只有 `preparation_id`，来源账本的路径要通过研究周期配对；没有周期引用的证据图，其发现无法连到来源。
3. **讨论记录之间没有版本链接。** `discussion-v1` 到 `discussion-v2` 的演进只能经由周期的 `previous_version` 看出，讨论记录本身没有 `previous_version`。
4. **schema 字段命名不一致。** 研究周期等记录使用 `schema`，`research-revision-v1` 使用 `schema_version`。
5. **阶段出口有两处表达。** 各阶段可能的出口写在[机器设计](../../../machine/design/research-guidance-cycle.json)中，检查器没有导出；视图另存了一份中文标签，两处需要同步。
6. **下一动作有多处来源。** 周期记录、检查器报告和证据图的 `review_decision.next_action` 各有一个“下一动作”，视图优先使用检查器的结果。

## 后续可以做什么

在真实课题目录上试用，观察读者能否借助视图说出研究经过；接入修订检查器的结果；根据上面的结构问题决定是否扩展记录字段。布局与交互仍是首版，欢迎按实际阅读需要调整。
