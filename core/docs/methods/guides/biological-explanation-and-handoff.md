# 从模型现象到生物学解释，再到人可以接手的决定

版本 `biological-handoff-v1.2`，2026-10-25。Optimus 与 S4PRED 案例用于说明对象身份和输入范围；[Yeast 工作例](../../../examples/research-support/preparation/choice-synthesis-example/biological-argument/README.md)进一步连接特征形成、标签证据与候选用途。相关研究与方法见[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)。实施步骤参见[可读过程](../../design/06-readable-process.md)和[功能与效用](function-and-utility-validation.md)。

## 什么时候需要展开解释

研究者需要从“当前模型或策略更有用”推进到“为什么”“如何改设计”或“下一步验证什么”时启用。只比较固定任务效用且已准确限域时，可以止于效用结论；不自动追加机制任务。

即使只交付固定任务结果，当程序ID、“全长”“原生”等术语可能让人误认研究对象时，也应补一段对象说明。先让人知道分析的究竟是什么，再决定是否展开机制。

## 先把程序中的对象翻译给人

围绕本次结论需要的区别解释四件事：**对象的可读名称与来源；实际进入程序的范围；标签/观测覆盖；它与读者熟悉的生物学对象有什么已知关系**。用一小段或短表即可；已有可信数据字典或来源中的充分说明可以直接引用。

PDB场景中，“提交polymer entity序列全长”说明输入序列包含哪些位置；天然参考映射说明对应哪个参考区间；实验坐标覆盖说明哪些位置有结构观测；计分mask再决定哪些位置进入分母。四者不能只用一个“完整蛋白”名称带过。表达标签、截短、突变和设计身份可能帮助读者理解面板，但仅凭名称或并列分数不能判断它们造成了模型误差。

[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)及[来源提取程序](../../../examples/s4pred/describe_entities.py)复用本轮已核字段：LC3B的提交截短记录与标签、HRP2的C64S和标签、nsp1的参考片段、ABLE的设计身份等。程序提取来源并计算明确的区间端点；文字说明这些字段用于辨认对象与解释范围。没有映射或字段为空时保留未知，不从缺字段推出天然完整，也不自动重建“正确天然序列”。

| 当前需求 | 为什么选择 | 合法替代与改判 |
| --- | --- | --- |
| 仅需澄清已分析对象 | 对照已有字段补名称、构建和范围，不改变输入、mask或原结果 | 可信数据字典/作者明确说明；未取得的关系写unknown |
| 构建身份会改变研究资格或目标 | 说明它为何影响当前问题，按已有选择规则判断，必要时另立研究修订 | 保持原面板并限域；另建有理由的新面板，不因已见分数悄悄删例 |
| 人需要理解单个高/低分 | 同时展示对象身份、参考/类别组成和分母，选择最能区分解释的下一证据 | 先做有依据的描述；不必立即作机制解释、同源搜索或结构预测 |
| 当前对象不是PDB蛋白构建体 | 使用本任务的操作单位，例如reporter变量区、细胞/供体或分子状态 | 按当前测量和用途解释；不套用PDB、UniProt、SIFTS字段清单 |

## 从对象到用途接通关系

输入、标签和指标分别说清以后，还要检查它们之间的理由是否足以支撑当前决定。先写读者准备怎样使用结果，再沿下面的关系回到来源。完整论证以所选用途为边界；一段正文、短表或已有的充分数据字典都可以承接。

**先说明对象怎样成为一行观测。** 蛋白、序列窗口、细胞、孔、供体、蛋白对和给定组分的复合物承担不同的研究问题。解释本次采样、选择、构建、截取或聚合怎样形成程序中的单位，并保留会改变判断的状态和实验条件。已有名称只能帮助定位，范围与粒度还需支持当前使用。例如一个固定面板的效用结论可以止于该面板；若改问未见家族的表现，才需要据新用途选择留出轴。

**再追到特征怎样生成。** 将关键列或嵌入接回原始材料、处理和上游模型：保留了哪种生物信息，压缩了什么，预测新对象时能否取得相同输入。规则、判别分数和监督学得的表示各有来源；当前分类器的训练划分只能说明自己的可见范围。若上游训练对象或版本尚未取得，说明它会影响哪种独立性判断，保留待核范围。有监督表示可以是合理输入，诊断信息重合则要查实际训练成员、数据流及评价用途。

**随后解释标签为何能作参照。** 标签可能来自直接测量、处理后的读出、数据库注释、人工分类或代理。写出它所对应的条件、粒度和目标，再判断与当前问题相接的依据。单标签定位、多个细胞状态、连续响应、关系和结构各按自己的定义解释。档案类别命中支持历史标签任务；迁移到新的独立定位、实验成功或机制问题，需要选择能补上相应连接的证据。

**最后把输出接到动作和评价。** 明确输出用于分类、排序、阈值采用还是提出可检验假设，并解释参照、独立单位、分母和选择预算为何适合这个动作。排序量首先按其排序事件解释；概率使用需要相应校准证据，机制使用需要能区分替代解释的观察或干预。先说明当前可以采取的决定，再给出最接近的合理替代、下一项有辨识力的证据，以及什么结果会使决定改变。

写成正文时，让每个关键连接都回答“依据是什么，因此现在怎么选”，并指出目前最弱的一次连接会限制哪项判断。一段综合依赖多份来源时，分别说明每份来源支持哪项连接，整段综合由研究者承担。[Yeast 连续论证](../../../examples/research-support/preparation/choice-synthesis-example/biological-argument/report.md)从历史蛋白定位任务出发，解释八项序列特征、档案标签、固定模型排序与同预算命中怎样相接，保留已接受的负结果。已有充分的局部解释继续保留；只有新用途需要时才另选补标签、独立评价或机制研究。解释路线交付连贯论证，新的经验问题沿[回应路线](revision-responses-and-acceptance.md)单独交接。

## 把解释变成可检查的选择

1. **先说清现象与读出。** 哪类对象、哪个体系、什么测量发生什么变化？区分标签、代理、直接观察和模型预测。MRL是由多聚核糖体分级读数估计的加载量；当前50nt变量区及reporter体系须保留，不直接扩写成所有mRNA的蛋白产量或体内功能。
2. **选一两个最有区分力的假设。** 从已读文献和当前现象给出理由，说明它能解释哪部分、解释不了什么。另列最接近的替代，如测量批次、子库设计约束、表示或校准失配。暂不寻找所有可能机制。
3. **在计算前写预测和改判。** 记录可观测变量、分层、方向或对比，以及出现什么结果应支持、修改或放弃当前解释。已经见过性能结果的后补分析须标明已知信息；不能追认成原研究预注册。
4. **从廉价但有辨识力的诊断开始。** 现有序列可计算组成/同聚物、已知motif及对应残差；先核ID、覆盖、稀疏项与子库，再看关联。可视化应显示能改变决定的反例和计数。预测结构、嵌入或模型归因各自有用途和不确定性，不自动成为分子真值。
5. **选择下一证据层。** 描述关联可以形成候选解释；匹配批次/构建背景的独立面板可检验迁移；受控序列改变及适配读出才可能进一步区分机制。依据当前目标选择，不要求同时完成全部层次。

## 一个具体例子：50nt UTR 中的 poly-U 与 AUG

Sample 等2019年的 S5 与 Fig.3 将设计域偏离联系到随机库中稀少的同聚物组成；Fig.1及 S29又涉及上游AUG与设计限制。这提供了两个可检验方向，不能直接解释本项目保存的ridge模型。

本轮先固定 `max-U-run` 与变量区AUG两项描述诊断，再读取新的分层结果。存储序列采用DNA字母，变量区连续T转为RNA连续U；ATG对应该区的AUG motif。这个motif描述局部序列；判断uORF还需确定转录本范围、阅读框、起止规则及相关证据。固定展示分箱仅服务本例，其他数据应按研究问题选择。

| 新观察 | 对解释采取什么动作 | 下一步可以是什么 |
| --- | --- | --- |
| 长U段伴随特定残差，且子库内仍有相同方向 | 保留“序列相关失准”的条件假设 | 检查匹配背景或独立测量；解释限于当前模型和面板 |
| 混合面板有关联，子库内减弱或方向相反 | 修改为子库/条件相关解释 | 优先补批次和设计条件，而非只增加重采样 |
| 方向与假设相反或没有可见差异 | 放弃原方向或保留证据不足 | 研究校准/表示等其他解释，不挑新阈值挽救原说法 |
| 关键分层为空或很稀疏 | 显示计数并保留缺口 | 获取合适对象；不把空格画成零效应 |

原文/补充阅读范围和书目见[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)。本轮分别保存已知结果、预定新分析和新观察。

## 怎样交给人

读者尚不熟悉课题时，先按[研究起点的说明](../../design/06-readable-process.md#先让读者看见研究从哪里开始)，让具体对象、实验现象或实际需求进入叙述，再展开当前选择和证据。原作者的起点与本轮接续动机沿各自来源讲清。 按读者背景补足对象作用、机制、操作与读数之间的前文，缩写和比较词在第一次使用时说明；参照[逐句连接](../../design/06-readable-process.md#让下一句话有可依靠的前文)检查读者是否需要自行填补推理。

篇章随任务调整，读者应能顺着下面的逻辑理解，不必每次填固定栏目。对关键步骤采用[可读过程](../../design/06-readable-process.md)的说明结构与读者验收，让目的、操作、观察和下一步连成解释：

- **现在怎么选。** 先说当前可采取的决定，说明依赖的用途和条件。
- **为什么。** 用一幅主图或简表给绝对效应、关键对照和会改变选择的反例；用自然语言解释指标、变量与测量的关系。
- **还有哪种解释。** 只展开最重要的一两个，并说明哪项观察会把它们区分开。
- **下一位先做什么。** 给具体输入、用途、首动作、可交付结果与接受/停止依据。摘要可追溯全文和原始工件。

生物图形可用结构文件、序列特征、二维结构或分子渲染辅助解释。选择工具应服务当前问题；预测、示意与实验结构分别标记。先用已有可复现的低成本呈现，工具环境、真实调用、输入/输出身份另有回执。

## 接受依据

读者应能说清：观察到什么、目前更倾向哪项解释、为何仍有替代、什么证据会改变判断，以及接手后的第一步。报告可以没有机制结论，但不能将效用、相关、示意图和机制互相替代。执行成功、方法复核与人的科学认可分别登记。
