# 综述优先：先看清证据与方法，再决定研究问题

当领域中的问题、术语、测量或候选方法尚未理清时，先做一份可独立交付的证据综述。它可以从宽泛主题开始，再根据阅读结果逐步聚焦；每次检索和笔记修改不必先封存。初始范围、关注点及重要改变的理由要保留，交付时说明实际覆盖的来源和材料版本。

本指南按研究准备目标组织文献查找与证据综合。系统综述、荟萃分析或其他有专门规范的综合任务，应另选与该目标相符的方法协议。

## 1. 说明为什么需要综述

先写下希望理解的生物学对象、过程或使用场景，以及当前不确定之处。区分：

- 已能提出的问题，但还需要核对证据和方法；
- 术语、评价对象或领域路线还不明确，需要先画出全貌；
- 当前证据不足以支持下一步，综述的交付目标是说明缺口或收窄主张。

记录初始主题、对象层级、关键术语、关注的测量或结果，以及本轮不处理的范围。综述目的可以是解释一类现象、比较方法、查明证据分歧或提出下一步问题。

## 2. 建立可修订的查找计划

先按本轮用途绘制问题地图，把会改变理解或选择的条件关系列为分支。初稿形成后，沿[覆盖与收束](review-coverage-and-closure.md)逐项检查，再决定整理已读内容、有界补查或结束。首次地图与重要修改分别保留，检索期间可以自由调整查询。起稿模型与推理强度按当前任务、资源和实际表现选择；关键争议、版本判断与方法取舍再有针对性地增加核证投入。

按问题选择数据库或已有搜索工具，把每次查找的实际平台、日期和完整查询保存到来源账本。再记录日期范围、语言、文献类型、纳入与排除条件、返回规模或平台限制，以及失败和无结果的路线。对已经确定的 DOI、PMCID 或原件链接，使用[资料获取分流](../source-acquisition-routing.md)规划和取得正文、补充材料等来源。

明确什么材料能够回答本轮问题。可把研究论文、综述、预印本、补充材料、协议、代码和数据分别记录。排除来源时写理由，避免只留下最终入选材料而看不见筛选边界。

检索和阅读推进时可以逐步修订计划。重要范围、查询、纳入规则或解释变化，记录修改前后的版本及理由；交付时固定本轮覆盖快照，包括检索范围、日期、实际读过的材料及尚未覆盖的关键来源类型。

## 3. 识别同一工作的不同版本

给每个来源完整书目信息和唯一 source_id，并给同一研究工作一个稳定 work_id。预印本、期刊终版、补充材料、协议、代码和数据可以是不同来源记录，但应通过版本家族和关联关系连接。

阅读与结论有关的确切材料。可能包括正文、补充方法、图表、代码、数据字典或数据本身。记录实际读了哪些页、节、图表、文件或字段；仅从摘要、元数据或他人转述得知的内容，不写成已阅读全文。

分别记录每项来源的取得进度和实际阅读范围：

| 取得状态 | 记录内容 |
|---|---|
| 尚未尝试 | 已列入计划，尚未发起获取 |
| 已尝试 | 获取请求已发起，记录结果或失败原因 |
| 已取得 | 保存了可识别的材料版本和来源位置 |
| 无法获得／受限 | 记录来源返回状态、许可或访问条件 |
| 状态待确认 | 仍需核实来源、版本或获取情况 |

| 阅读状态 | 记录内容 |
|---|---|
| 未读 | 尚无内容阅读记录 |
| 元数据已读 | 仅查看书目信息或摘要 |
| 部分阅读 | 标出已读部分及起止位置 |
| 正文已读 | 标出实际阅读的正文范围 |
| 支持材料已读 | 标出补充材料、图表或协议范围 |
| 代码或数据已检查 | 标出文件、函数、表或字段位置 |

把许可或访问条件与取得、阅读记录关联，未确认项目保留待核状态。已获取材料继续通过阅读状态说明实际覆盖。

## 4. 把作者报告和证据综合分开

每条关键发现都保留来源定位和作者表达的范围，再写本综述如何解释它。区分作者报告、跨来源综合和研究者推断。一个结论若依赖具体措辞或数值，应回到原文或原始表格定位。

整理证据前先比较：

| 需要核对的条件 | 可能影响的解释 |
|---|---|
| 生物对象、队列、采样、纳入范围和时间 | 结果适用的人群、系统或条件不同 |
| 测量、代理量、标签、数据预处理和参考来源 | 同一名称可能对应不同观察或真值 |
| 实现、参数、基线和信息用途 | 方法执行或可见信息不同 |
| 评价单位、分母、划分、筛选与统计量 | 比较对象、独立性或估计量不同 |

将证据支持的差异解释与工作假设分开记录。证据解释应给出来源位置，并说明数据、测量、实现或评价条件怎样联系到观察到的差异；可能解释差异但尚待核验的机制，列为工作假设并写明区分它的证据。资料不足时保留双方的来源依据和待核点，争论维持开放。共享队列、样本、数据集或版本家族作为关联证据标记；独立复现依据独立数据与研究过程判断。综合结论依据证据质量、适用条件和独立性，论文数量用于说明覆盖范围。

综合每项主要证据时，按目标评议测量与主张是否相符、对照和基线是否合适、评价单位与选择边界是否清楚，以及不确定性和未报告信息怎样影响判断。记录支持范围、关键缺口和可能改变综合结论的证据。可按需要采用[测量到主张](measurement-to-claim.md)和[统计单位](statistical-units-and-selection.md)指南。

## 5. 比较方法候选

用当前问题而不是方法名称作为比较起点。每个候选路线至少回答：

| 项目 | 需要说明的内容 |
|---|---|
| 用途 | 它回答哪类描述、比较、预测或解释问题 |
| 前提 | 目标对象、数据结构或测量需要满足什么条件 |
| 信息需求 | 需要哪些输入、标签、参考、重复或独立评价 |
| 代价 | 资料、计算、时间、许可或专业判断的主要成本 |
| 失败情形 | 哪些输入缺失、偏差、混杂或结果会使它不适用 |
| 替代与选择 | 可行替代是什么，当前为什么选或暂不选，以及什么会改变决定 |

将作者在特定研究中的做法与对当前问题的建议分开。每项方法选择都注明对应的数据、队列或主张条件，再据此决定当前研究是否采用。

## 6. 从证据缺口形成候选问题

从仍未解决的关系提出候选问题，并说明：

1. 这个问题对理解生物学对象、解释结果或作出使用决定有什么意义；
2. 现有工作已经回答什么，仍缺的关系或证据是什么；
3. 哪种新观察、比较或分析能够区分候选解释；
4. 什么结果会使当前解释、方法或后续行动改变。

适用时再写假设，把它连接到可区分的预测与竞争解释。描述、制图或证据整理可以按目标组织问题，并在记录中说明假设是否适用。

如果候选问题涉及新颖性，将判断限定在本次记录的检索范围、日期和查询式：列出已见的相关工作，以及在这些来源中尚未找到的匹配。保留覆盖快照；更广范围的新颖性结论需要相应扩展检索支持。

## 7. 组织可读的综述交付

用[来源与证据模板](../../../examples/research-support/preparation/README.md)连接实际阅读、发现、方法和问题，以[综述主文提纲](../../../examples/research-support/preparation/REVIEW.template.md)展开面向读者的论证。

让综述的论证顺序回答读者的问题：研究对象和术语是什么，哪些结论在什么条件下得到支持，方法选择怎样影响结果，分歧是否已由条件差异解释，仍缺什么证据，以及下一步的候选问题是什么。

可以用概念图、方法比较表、证据矩阵或时间线帮助解释关系。图表应显示它表达的对象和条件，不用论文数量暗示共识。术语表应标出来源之间的不同用法。引用定位到支持相关句子的正文、补充材料或代码/数据位置；把作者原话与本综述的解释分开。

## 8. 结束本轮并选择下一步

初稿或首交已固定、仍有会改变选择的遗漏时，可沿[重读与视角切换](review-choice-synthesis.md#固定交付后主动重读相关原文)先确认交付版本，再完整重读相关原文，保留实际阅读和补充材料范围。新稿另存后，继续下面的用途判断。

先回到问题地图：关键关系是否已经有依据，哪些只是提名、尚未进入综合或材料不可得。需要补查时写明它可能改变什么、责任人、时间与新增材料上限；达到边界仍未解决时重新选择补充、收窄或讨论。非关键分支可以说明后留待以后；改变用途时保留旧地图和理由。

根据本轮目标作决定：

- **综述交付：** 当前覆盖足以回答综述目标，未解决问题和覆盖边界已说明；
- **继续定向阅读：** 某些关键来源、版本、补充材料或分歧仍可能改变当前综合；
- **暂缓或停止：** 资料不可得、成本不匹配或当前证据不能支持有用结论；
- **转入研究：** 明确选定一个问题、研究用途和方法，并记录为何现在进入数据准备。

就绪取决于目标所需证据是否覆盖、关键争论是否已比较、剩余未知是否明确，以及新增材料是否仍可能改变选择；按目标判断覆盖，不设统一篇数目标。只有转入研究时才建立新的 study bridge 和首计划；综述也可以独立作为交付。

选择新课题方向前，用[研究推进主线](research-guidance-cycle.md)组织一次解释与讨论：给出有理由的候选方向、当前推荐、成本与改变选择的条件，保存人实际提出的意见和约束。后续评价可沿同一主线回到原判断。

转入后的数据条件、首审计和工件接缝见[研究前期准备入口](research-preparation.md)及相应的[资源缺口](resource-gap-loop.md)、[计划封存](plan-seal-and-first-execution.md)、[统计单位](statistical-units-and-selection.md)和[生产—消费](artifact-producer-consumer.md)指南。
