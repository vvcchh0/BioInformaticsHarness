# 研究问题驱动的条件工作例

这些例子把现有方法卡接到具体的研究选择。按当前问题取用；来源、作者做法与新增建议分开，保留可改变结论的观察和合法替代。

| 当前研究问题 | 工作例 | 要形成的判断 |
|---|---|---|
| 读者仍不清楚研究为什么开始、怎样提出问题 | [从观察到研究起点](research-origins.md) | 把具体对象、现象、未解关系与有辨识力的比较连成叙述 |
| 整体分数高，是否包含当前任务需要的特异信息 | [共同信号与任务特异能力](common-and-task-specific.md) | 匹配信息条件，选择能区分共同解释与特异能力的比较 |
| 根据置信输出采用、保留或拒用预测 | [置信度到使用决定](confidence-to-decision.md) | 分清排序、区间校准和实际策略效用，各按用途验收 |
| 从快照推断变化方向、时间或轨迹 | [动态过程解释](dynamic-process-interpretation.md) | 连起观测、假设、推断和图形，决定解释及使用范围 |

各页给出适用问题、可选路线和会改变结论的条件。开始前先选最接近的研究问题，再联用相关方法卡。论文和设计入口见[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)。

## 从综述整理的条件工作例

这一组从测量、表示、推断到使用，展开现有指南中的方法取舍。每页以一个假设研究问题串起输入、可选路线、比较方式、改判条件与向人的交接。

| 当前研究问题 | 工作例 | 要形成的判断 |
|---|---|---|
| 固定预算下增加重复、细胞覆盖还是深度 | [测量设计与重复](measurement-design-and-replication.md) | 让测量单位、独立重复和推广目标一致 |
| 空间梯度来自组成、细胞内表达还是预测层 | [空间信号与捕获](spatial-signal-and-capture.md) | 区分实际捕获物、目标量与估计层 |
| 图参考与其他表示增加了哪些可评价对象 | [表示与参考偏差](representation-and-reference-bias.md) | 对齐变异事件，共同域比较与新增覆盖分开 |
| 多组学整合是否有可部署的响应预测增益 | [整合与响应目标](integration-and-response-target.md) | 对齐标签、留出轴、缺失规则和评价分母 |
| 标签和快照能约束哪一层历史 | [历史与状态推断](history-and-state-inference.md) | 按克隆、分支和状态证据选择可回答的问题 |
| 现有工具与数据能识别怎样的因果问题 | [工具变量与可识别性](causal-instruments-and-identifiability.md) | 匹配个体/汇总输入、估计目标与识别条件 |
| 对接结果的问题出在生成、评分还是用途 | [采样、评分与使用](sampling-scoring-and-use.md) | 用候选集合和选中结果的配对读出定位问题 |

来源覆盖11篇综述与方法导读，另有1篇可重复计算背景文章。各页链接原文与相关指南，完整书目和阅读范围见[参考文献](../../../REFERENCES.md)。这些例子供制定方案和讨论取舍时使用，下一步可选择与实际材料最接近的一例应用。
