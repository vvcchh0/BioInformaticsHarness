# 从置信度到使用决定：分开评价排序、校准与效用

版本：`research-facets-v0.2`，2026-10-20。以Evidential Deep Learning的分子性质预测工作作条件例；[公开研究设计与方法索引](../../../../docs/REFERENCES-AND-DESIGN.md)支撑本次细化。首稿使用原有冻结指导，未使用本工作例；本工作例自身的应用效果另验。没有训练模型或开展新的筛选。

## 何时启用

当研究者准备根据置信分数采用、暂存、拒用预测，或决定优先取得哪些标签时使用。先写清**谁会根据输出采取什么行动，错误会造成什么损失，允许多少对象暂不判断**。若只是展示模型输出而不据此作决定，可以只解释分数语义。

Evidential论文实际分别考察了不确定性与误差的排序关系、区间校准及正则项的作用、主动学习和回顾性候选选择。不能把该论文概括成“只做排序”。这些证据又各有评价范围，回顾性策略收益不能直接当成一次新前瞻筛选的结果。[论文及完整引文](https://doi.org/10.1021/acscentsci.1c00546)。

## 先向人解释模型给的是什么

以水溶解度预测为例，模型可能给出一个预测值和一个不确定性量。我们希望知道：它是否能把更容易预测准确的分子排在前面；它给出的范围是否经常包含实际测量；按这个范围决定是否使用预测，是否比当前方案更有用。三件事相关，但不能互相替代。

先记录输出的定义、单位、方向与计算路径：它是任意排序分数、预测方差、参数/模型不确定性，还是包含观测噪声的预测分布？本文Evidential回归用高阶分布输出参数；只有把所用参数与实际计算对应起来，才能知道下游使用了哪一种不确定性。具体实现应定位论文的 `confidence-evidential` 分支；通用Chemprop主分支的存在不足以代表该算法。

一个具体接缝是：本轮保存的`predict`静态快照将不含β的inverse evidence放入`c`，将其乘β后放入`var`，返回值又受参数控制。最终评价还经过本轮未提供的estimator。因此，看到`confidence`字段或四参数并不能确定筛选实际消费了哪一量。先取得导出列、参数、scaler、实际消费者版本和一条消费记录，再决定做排序还是区间评价。这里观察的是2026年分支快照，不补认论文历史运行。

## 两条可交接的小路线

| 条件与目的 | 首先交接什么 | 下一步及原目标边界 |
|---|---|---|
| 能取得标签覆盖完整的性质面板及保存输出，例如溶解度任务 | 分子ID、目标单位、同一预测器的均值与所用U、开发/评价历史 | 在固定分子数量下比较误差与接受风险；若要数值区间再接校准。该路线不回答抗菌候选的应用收益 |
| 复核标注稀疏应用库中的富集，例如论文OD600案例 | 全候选预测、测量掩码、已测标签、历史入选记录及各阶段ID | 并列记录候选、入选、已测、命中和被暂缓的已知命中；匹配人数/预测值条件后比较。未测不填成阴性 |

## 根据用途选验收路线

| 使用问题 | 优先读出与必要材料 | 可以接受的合法替代 |
|---|---|---|
| 在有限数量中优先采用较可靠预测 | 保留比例与实际误差的关系；同一批对象的预测、分数与独立标签 | 已保存且身份明确的输出；与简单距离/其它低成本排序或无筛选策略比较 |
| 将区间作为有数量含义的范围 | 名义覆盖与经验覆盖、区间宽度及适用分组；明确所预测随机量 | 在独立校准集上作适合假设的重校准；若只能支持排序，则只作排序决定 |
| 按不确定性决定是否采用预测 | 接受集的风险与覆盖率、拒用比例和实际使用成本 | 采用更保守的适用域或直接保留人工/后续测量；不强制每例输出概率 |
| 优先补标签以改善模型 | 相同初始资料、候选池、标签预算和更新条件下的学习曲线 | 随机补充、按任务性质构建的简单策略；没有标签回放条件时先交设计 |
| 选择有限候选满足某个用途 | 固定预算下的真实任务终点、失败和选择链 | 简单按预测值选择或当前研究策略；与探索型策略比较时说明效用取舍 |

这里的“保留比例”是被采用的对象占原候选的比例，与预测区间的“覆盖率”不同。报告中应写全名称，避免两个coverage混用。

## 实际工作顺序

1. **固定使用总体和错误事件。** 例如当前化学空间里预测误差超过某个有用途依据的容许量，或选定预算下未达到目标的对象比例。容许量、损失和拒用成本未确定时，把它作为具体待决项；不要先套一个数值。
2. **分开拟合、校准、选阈值与最终评价。** 数据可以复用到开发环节，但最终效果应在相应保护范围内评价。保存分子/来源/时间等划分轴、相似性与表示；将选阈值用过的标签追溯到开发阶段。论文中的超参数与默认值是该工作选择，不能替代新任务的校准。
3. **先验证最接近行动的读出。** 排序用途先看各保留比例的误差、被排除对象及样本数；区间用途同时看覆盖和宽度；拒用用途画接受风险与接受比例。不能只报告留下来的最好一小组，而省略其余对象与覆盖代价。
4. **比较一条当前可用的替代。** 对纯排序，可以用简单适用域/距离或无筛选策略；对标签获取，可用随机策略。若目标是区分“不确定性”的增益，要在预测器、候选池和预算上作相应控制；若目标只是比较整套系统效用，则允许系统不同，但不单独归因于UQ模块。
5. **在将要使用的变化轴上复核。** 开发总体内的良好覆盖不自动延伸到新骨架、新测量体系或新时期。根据用途选择一个相关外部范围或分组，分别报告表现。无标签的域外分数可以提示谨慎，不能直接验收域外误差或校准。
6. **把决定写成可更改的规则。** 保存当前适用范围、阈值来源、被接受/保留/拒用的对象与理由，以及需重新校准或停止使用的证据。实际运行时再记录阈值与输入是否被消费者使用。

接受集为空时，风险无定义；没有标签时，风险未知。高不确定对象可以转入补证或主动学习队列，“拒用当前预测”不能自动变成“该分子没有价值”。

来源定位：正文“Uncertainty Benchmarking”“Calibration and Tunability”（Fig. 3–4、Table 1）及主动学习、贝叶斯优化和回顾性选择各节；支持材料中的对应任务与参数。作者报告与本例新增的前瞻交接步骤分别保存。

## 什么结果会改变决定

| 观察 | 对使用决定的影响 |
|---|---|
| 较低不确定性的对象确实误差较低，但概率/区间覆盖不足 | 可以按已验证范围作相对排序；数量化区间用途先重校准或限域 |
| 覆盖看似理想，但区间宽到不能支持当前用途 | 当前精度不足以支持该操作；检查所需精度、效用阈值或其他适用路线 |
| 采用/拒用规则在目标范围内达到事先说明的风险与覆盖要求，且优于适用替代或满足成本约束 | 支持该范围与规则的使用，保留未接受对象 |
| 只在极少数精选对象上好，或同预算简单策略同样好 | 重新评估增加UQ的实际价值；保留限定排序或选用较便宜方案 |
| 外部体系的覆盖/风险已偏离容许范围，或分数不再区分误差 | 缩小使用范围、重新校准，或停止这条自动采用规则 |
| 缺独立标签、错误容许或成本依据 | 交付有明确缺项的设计；不把分数大小转换成已验收的风险 |

用与当前行动相配的读出来判断效用。某种方法在一项任务上较弱时，可继续评估其他符合目标的UQ路线。比较范围和证据强度由行动成本决定；按需选择任务比较，无需默认完成主动学习、域外评测和区间校准三套实验。

## 最小交接及Harness入口

一份可用交接应包含：对象/标签谱系、保存预测和所用不确定性定义、数据用途边界、选定行动与替代、具体读出/计算、改判条件、缺失出口和人读解释。没有运行时，保留为设计；运行后附逐对象采用决定与实际消费回执。
